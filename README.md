# Soma de Números Ímpares em Java

## 📌 Descrição
Programa desenvolvido em Java que recebe dois números inteiros e calcula a soma de todos os números ímpares existentes entre eles, sem incluir os valores informados.

## 🛠️ Tecnologias utilizadas
- Java
- Scanner para entrada de dados
- Estrutura de repetição `for`
- Estrutura condicional `if`
- Operador de módulo `%`

## ⚙️ Como funciona
1. O usuário informa dois números inteiros.
2. O programa verifica qual número é maior e organiza os valores em ordem crescente.
3. Utiliza um laço `for` para percorrer os números entre os dois valores.
4. Verifica se cada número é ímpar usando `i % 2 != 0`.
5. Soma os números ímpares encontrados.
6. Exibe o resultado final.

## 💻 Exemplo de execução

**Entrada:**
```text
6
-5
```

**Saída:**
```text
5
```

**Explicação:** Os números ímpares entre -5 e 6 são -3, -1, 1, 3 e 5. A soma desses valores é 5.

## 🎯 Objetivo
Praticar estruturas de repetição, condicionais, operadores aritméticos, acumuladores e a organização de valores em Java.
